# 🏋️‍♂️ FitLog — Your Ultimate Workout Companion

**FitLog** is a modern, high-performance web application designed to help fitness enthusiasts discover, organize, and track their daily workout routines with ease. Built with Next.js and styled with Tailwind CSS & DaisyUI, it delivers a fast and dynamic user experience.

---

## 🛠️ Technologies Used

### **Frontend & Framework**
* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Library:** React 19
* **Styling:** Tailwind CSS & [DaisyUI](https://daisyui.com/)
* **State Management:** React Context API
* **Icons & Assets:** React icons, Next.js Image Optimization

### **Backend & API**
* **Data Fetching:** Native Fetch API with Caching (`force-cache` & `revalidate`)

---

## ✨ Key Features

* **🏋️ Detailed Workout Library:** Explore a wide range of exercises covering major muscle groups with full descriptions, difficulty levels, target equipment, and step-by-step instructions.
* **📅 Personalized Day Plan Management:** Easily add or remove exercises to build your daily "Today's Plan" and manage a capped set of active lifts.
* **⭐ Saved Workouts Collection:** Save your favorite exercises to a custom library for quick reference and future workout sessions.
* **⚡ Smart Sorting & Real-Time Stats:** Filter and sort workouts by rating, duration, or calories burned while tracking live totals for exercises, total minutes, and calories.
* **⚡ Optimized Performance & Dynamic UI:** Built with server-side caching, DaisyUI skeleton loading states, active route highlights, and responsive design for mobile and desktop screens.
